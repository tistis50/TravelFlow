

Не исправлять до выполнения следующего модуля.

1. После изменения существующей записи появляется сообщение «Расход добавлен.» вместо «Расход изменён.». Воспроизведение: создать запись, нажать «Изменить», поменять сумму, сохранить. Сама операция UPDATE корректна, число записей не увеличивается. Исправление позднее: отдельное значение msg=updated при редактировании и текст уведомления.
2. Если отфильтровать журнал по поездке без расходов, при наличии других записей выводится «Записей пока нет» вместо «По выбранной командировке расходов нет». Воспроизведение: добавить расход для № 2, выбрать в фильтре № 12. Выборка корректно пуста, общие показатели верны. Исправление позднее: раздельные тексты пустого реестра и пустой отфильтрованной выборки.

Оба дефекта касаются исключительно формулировок интерфейса, не затрагивают SQL-данные, права доступа или выполнение операций. Для 05.03 необходимо провести тесты, оформить журнал дефектов, исправить и повторно проверить.
